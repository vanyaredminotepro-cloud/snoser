# Мод «Безусляндия» для Hearts of Iron IV

Этот мод добавляет новую страну `BZU` — **Безусляндию** — и базовый контент для старта кампании.

## Что исправлено для работоспособности
- Обновлена совместимость мода до **1.17.4** (`supported_version="1.17.4"`).
- Добавлен `on_actions`, чтобы скриптовые события запускались в начале новой партии.
- Локализация сохранена в формате UTF-8 с BOM (важно для HOI4).

## Что есть в текущей версии
- Тег страны `BZU`, цвета и базовые параметры страны.
- Исторический файл страны с лидером и столицей в **Гамбурге** (`state id 42`).
- Решение для Германии: **«Провозгласить Безусляндию»** в западной части Германии.
- Новостное событие о появлении страны.
- Стартовая ветка национальных фокусов для `BZU`.
- СССР косметически отображается как **Россия** (локализация `SOV_RUS`).
- На старте применяется упрощённый мировой сценарий:
  - для СССР — приближение к современным границам через освобождение республик;
  - для Африки — объединение региона под единым государством;
  - для Южной Америки — формирование блока стран с целью дальнейшего объединения.

## Как создать Безусляндию в игре
1. Начните новую игру за **Германию (GER)**.
2. Убедитесь, что Германия **не находится в войне**.
3. Убедитесь, что **Гамбург (state id 42)** контролируется Германией.
4. Убедитесь, что фокус **GER_anschluss** ещё не завершён.
5. Откройте вкладку решений и выберите **«Проект Безусляндии» → «Провозгласить Безусляндию»**.
6. Потратьте `75` политической власти и дождитесь выполнения решения (`30` дней).

После этого появляется страна **BZU (Безусляндия)** со столицей в Гамбурге.

## Установка
1. Скопируйте папку мода в каталог `Documents/Paradox Interactive/Hearts of Iron IV/mod/bezuslyandiya`.
2. Убедитесь, что `descriptor.mod` указывает на путь `mod/bezuslyandiya`.
3. Включите мод в лаунчере HOI4.

## Если мод «не работает»
1. Версия игры должна быть **1.17.4** (или совместимая с этим патчем).
2. Папка мода и `descriptor.mod` должны лежать в `Documents/Paradox Interactive/Hearts of Iron IV/mod/`.
3. В лаунчере должен быть включён именно этот мод, без конфликтующих модов на карту/страны.
4. Для решения по Безусляндии нужны условия из раздела выше (Германия, мир, контроль state 42, без `GER_anschluss`).
5. Для стартовых событий начните **новую** кампанию (on_startup не применяется к старым сейвам).

## Технические заметки
- Решение на создание страны доступно только Германии.
- Используется `state id = 42` (Гамбург).
- В моде применён упрощённый скриптовый сценарий «современных границ» без редактирования файлов карты/provinces.
