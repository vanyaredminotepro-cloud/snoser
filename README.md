# Мод «Безусляндия» для Hearts of Iron IV

Мод переведён на сценарий автоматической инициализации мира в начале новой кампании.

## Версия и совместимость
- Поддерживаемая версия игры: **1.17.4**.
- Локализация в UTF-8 с BOM.

## Что теперь делает мод на старте игры
1. **Безусляндия (`BZU`) создаётся автоматически** в Гамбурге (`state id 42`) без решений.
2. СССР косметически показывается как **Россия** и освобождает постсоветские республики (Украина, Беларусь, Прибалтика, Молдова, Кавказ, Центральная Азия).
3. Создаются/используются отдельные теги и страны:
   - `OBS` — Обоссляндия;
   - `CRL` — Картели;
   - `LNR` — ЛНР;
   - `AFR` — Союз Африки.
4. На старте применяется скриптовое перераспределение границ:
   - Африка передаётся `AFR`;
   - Южная Америка передаётся `CRL`;
   - ЛНР получает state `228`;
   - Обоссляндия получает state `227`;
   - Безусляндия получает state `42`.

## Важно
- Все изменения применяются к **новой кампании** через `on_startup`.
- Без запуска новой игры стартовые события не сработают.

## Установка
1. Скопируйте мод в `Documents/Paradox Interactive/Hearts of Iron IV/mod/bezuslyandiya`.
2. Проверьте `descriptor.mod` (`path="mod/bezuslyandiya"`).
3. Включите мод в лаунчере.
