# Мод «Безусляндия» для Hearts of Iron IV

Этот мод добавляет новую страну `BZU` — **Безусляндию** — и базовый контент для старта кампании.

## Что исправлено для работоспособности
- Обновлена совместимость мода до **1.17.4** (`supported_version="1.17.4"`).
- Добавлен `on_actions`, чтобы скриптовые события гарантированно запускались в начале партии.
- Локализация сохранена в корректном формате UTF-8 с BOM (важно для HOI4).

## Что есть в текущей версии
- Тег страны `BZU`, цвета и базовые параметры страны.
- Исторический файл страны с лидером и стартовой политикой.
- Решение для Германии: **«Провозгласить Безусляндию»**.
- Новостное событие о появлении страны.
- Стартовая ветка национальных фокусов для `BZU` (восстановление, промышленность, армия, центризм).
- СССР косметически отображается как **Россия** (локализация `SOV_RUS`).
- На старте игры для СССР применяется скрипт с приближением к современным границам: освобождаются союзные республики.

## Как сделать (создать) Безусляндию в игре
1. Начни новую игру за **Германию (GER)**.
2. Убедись, что Германия **не находится в войне**.
3. Убедись, что **Берлин (state id 64)** контролируется Германией.
4. Убедись, что фокус **GER_anschluss** ещё не завершён.
5. Открой вкладку решений и выбери **«Проект Безусляндии» → «Провозгласить Безусляндию»**.
6. Потрать `75` политической власти и дождись выполнения решения (`30` дней).

После этого в Берлине появляется страна **BZU (Безусляндия)**.

## Где появляется Безусляндия
- После принятия решения за Германию страна появляется в **Берлине** (state id `64`).
- Условие: регион `64` должен быть под контролем Германии.

## Примечание по «современным границам»
В рамках текущего мода «современность» сделана в упрощённом виде: при старте игры СССР освобождает ряд республик (Украина, Беларусь, Прибалтика, Молдова, Кавказ и часть Центральной Азии), чтобы приблизиться к современному контуру России без редактирования карты/provinces.

## Установка
1. Скопируйте папку мода в каталог `Documents/Paradox Interactive/Hearts of Iron IV/mod/bezuslyandiya`.
2. Убедитесь, что `descriptor.mod` указывает на путь `mod/bezuslyandiya`.
3. Включите мод в лаунчере HOI4.

## Если мод «не работает»
Проверьте по шагам:
1. Версия игры должна быть **1.17.4** (или совместимая с этим патчем).
2. Папка мода и `descriptor.mod` должны лежать в `Documents/Paradox Interactive/Hearts of Iron IV/mod/`.
3. В лаунчере должен быть включён именно этот мод, без конфликтующих модов на карту/страны.
4. Для срабатывания решения по Безусляндии нужны условия из раздела выше (Германия, мир, контроль state 64, без `GER_anschluss`).
5. Если не сработала реформа СССР, начните **новую** кампанию (on_startup не применится к старым сейвам).

## Технические заметки
- Решение на создание страны доступно только Германии.
- Используется `state id = 64`; при модифицированной карте его нужно скорректировать.
